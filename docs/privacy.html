Send to WhereGoes: privacy notice

This extension was created with ChatGPT (OpenAI GPT-6). It is independently maintained and is not affiliated with WhereGoes.

When you deliberately choose a link from the context menu or submit a URL via the toolbar popup, the extension opens WhereGoes and places that URL in its form. WhereGoes receives the URL when it is submitted. Tracking URLs may contain personal, private or one-time data, so avoid submitting sensitive links.

The extension has no developer analytics, advertising, remote executable code or server-side tracking. It does not independently follow tracking URLs, alter unrelated websites or store your browsing history. WhereGoes is a separate service, and its privacy policy applies once the link is submitted to its website.

Browser permissions are restricted to the link context menu, active page access on explicit popup activation, and the WhereGoes website for form filling. It does not need access to all websites.
